# BITCOIN
ANALYSE UNE TRANSACTION BITCOIN
# TP3 Blockchain : Analyse d'une transaction Bitcoin (TestNet4)

*Auteur :* Abir Benomar[cite: 1, 5]

## 1. Question choisie
Comment installer, configurer un portefeuille Bitcoin sur le réseau de test (TestNet4) et analyser la réception de transactions ?[cite: 1, 2, 5]

## 2. Démarche suivie
1. *Installation :* Téléchargement et installation du logiciel Wasabi Wallet sur Windows[cite: 5].
2. *Configuration :* Création d'un nouveau portefeuille (Wallet b) et connexion au réseau de test *TestNet4* avec synchronisation des blocs[cite: 6].
3. *Expérimentation :* Réception de deux transactions de test sur le portefeuille afin d'observer la mise à jour du solde et l'historique des opérations[cite: 6, 7].

## 3. Résultat obtenu
Le portefeuille a bien été synchronisé avec le réseau TestNet4 et a permis de recevoir deux transactions de test (0.00353774 BTC puis 0.00124111 BTC), confirmant le bon fonctionnement des échanges sans utilisation de fonds réels[cite: 3, 7, 8].
